# CareerPilot — AI Job & CV Assistant

CareerPilot is a mobile-friendly, Cloudflare Pages-ready web MVP.

## Included
- Dashboard
- CV Builder
- Modern, Professional and ATS-Friendly template choices
- CV preview
- PDF export
- Local browser save
- Job keyword matching
- Cover Letter generator
- Interview Prep
- Responsive mobile layout

## Deploy
Connect this GitHub repository to Cloudflare Pages.
Framework preset: None / Static HTML.
Build command: leave blank.
Output directory: / (repository root).

## Important
This version does not expose any paid AI API key. Real AI, accounts, cloud CV storage and secure AI calls can be added later using a backend such as Supabase Edge Functions.
